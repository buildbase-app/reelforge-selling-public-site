ReelForge is a studio for making short vertical videos (Reels, Shorts, TikToks) that you run on your own computer or server. You describe the video as a storyboard, ReelForge renders each scene with an animation engine and assembles the result into one MP4.

## How it will be sold

- **Once, not as a subscription.** You buy the source code with install documentation and run it yourself. There is no render service run by us, and any AI provider is optional and your own.
- **Optional services.** Help with installation and support can be bought on top.
- **Prices are not set yet.** The [pricing page](/pricing) shows what can be bought, read live from the store. Until something is on sale, it says so.

## What is ready today

This store is open: you can read about ReelForge, [join the waitlist](/waitlist), create an account and read the draft legal pages. ReelForge itself is in early access and **not on sale yet**.

## Licensing you should know about

ReelForge includes Remotion-based templates. Remotion is free for individuals and companies of up to 3 people; larger companies need their own Remotion licence ([remotion.dev/license](https://www.remotion.dev/license)). ReelForge also includes Motion Canvas, HTML and HyperFrames engines.
